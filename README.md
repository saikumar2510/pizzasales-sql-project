# 🍕 Pizza Sales Analysis using SQL

## 📌 Project Overview
Analyzed pizza sales data to answer 13 business questions and provide insights to increase revenue and improve operations.

## 🛠️ Tools Used
- MySQL
- MySQL Workbench
- GitHub

## 📂 Dataset
- `pizzasales` table - contains order details, pizza types, quantity, price, date & time

## 📊 Business Problems Solved
1. Retrieve the total number of orders placed.
2. Total revenue generated.
3. Identify the highest-priced pizza.
4. Most common pizza size ordered.
5. List the top 5 most ordered pizza types.
6. Join the necessary tables to find the total quantity of each pizza category ordered.
7. Distribution of orders by hour of the day.
8. Join relevent tables to find the category-wise distribution of pizzas.
9. Group the orders by date and calculate the average number of pizzas ordered per day.
10. Determine the top 3 most ordered pizza types based on revenue.
11. Calculate the percentage contribution of each pizza type to total revenue.
12. Analysis of cumulative revenue over time.
13. Top 3 most ordered pizza types based on revenue for each category.

## 💡 Key Insights
- Peak ordering hours are evening time
- Classic category is the most ordered
- Large size pizzas generate most revenue

## 🔗 How to Run
1. Import dataset into MySQL
2. Run queries from p1.sql to p13.sql files
